# Клёв на Волге

PWA без сборщиков: оценивает вероятность клёва (0–100%) судака, щуки, окуня, жереха, сома и голавля на Волге по погоде Open-Meteo, сезону, времени суток и фазе луны.

## Запуск локально

```bash
python3 -m http.server 8765
```

Откройте http://localhost:8765.

## Установка на iPhone

Service worker и GPS работают только по HTTPS, поэтому выложите папку на любой статический HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages). Затем откройте сайт в Safari → «Поделиться» → «На экран „Домой“». После первого запуска приложение работает офлайн и показывает последний сохранённый прогноз.

## Структура

- `js/fish.js` — модели видов (предпочтения, веса по умолчанию, подсказки, советы) и векторные иллюстрации
- `js/model.js` — расчёт факторов, гармоническое среднее, лимитирующие факторы, объяснения
- `js/weather.js` — запрос к Open-Meteo, кэш в localStorage, тренды давления, оценка температуры воды
- `js/astro.js` — фаза луны
- `js/places.js` — точки от Твери до Астрахани
- `sw.js` — офлайн-кэш; при изменении файлов увеличьте `VERSION`
